# Security

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/joe-yeomans/ecsd/security/advisories/new). If that channel is unavailable, open an issue requesting a private reporting channel without disclosing vulnerability details.

Include the affected version, impact, and steps to reproduce. Do not include AWS credentials or private account data.

Security fixes are developed on `main`. There are no separately maintained release branches.
